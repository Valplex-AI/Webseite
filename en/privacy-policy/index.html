2. General information

This website provides information about our activities. It offers no registration, no user account and no online shop. We ourselves process personal data only where you provide it to us – in particular by email (see section 5).

The technical delivery of the website and the access data generated in that process are handled by GitHub as the hosting provider (see section 3). The legal basis for the processing described here is the General Data Protection Regulation (GDPR).

3. Hosting by GitHub Pages

This website is provided through GitHub Pages. The hosts are GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, United States, and, for the European Economic Area, GitHub B.V., Prins Bernhardplein 200, 1097 JB Amsterdam, the Netherlands.

3.1 What Valplex is responsible for

Valplex is the controller for the content of this website and for personal data that reaches us directly (in particular email inquiries). We do not use tracking, analytics or marketing services. We have no direct access to the server log files kept by GitHub.

3.2 What GitHub processes

GitHub provides the technical infrastructure. When the website is accessed, GitHub automatically processes technical access data in order to deliver the pages and to maintain the security and integrity of the service. According to GitHub, the visitor's IP address is logged and stored for security purposes, regardless of whether the visitor is signed in to GitHub. GitHub may also process the following data:

  • IP address
  • date and time of access
  • page / file requested
  • amount of data transferred
  • browser type and version, operating system, referrer URL

The legal basis for our use of GitHub Pages is Art. 6(1)(f) GDPR. Our legitimate interest lies in providing the website securely and efficiently without operating our own servers. Where GitHub processes this data for its own purposes (in particular the security and integrity of its services), it does so as an independent controller in accordance with its privacy statement. The storage period depends on the purpose of the processing and GitHub's contractual and legal obligations. Further information from GitHub on hosting via GitHub Pages is set out in the GitHub Pages documentation.

Processing in the United States or other third countries cannot be ruled out. Where personal data is transferred to a third country, the transfer is made only in compliance with Art. 44 et seq. GDPR and on the basis of suitable safeguards, in particular an applicable adequacy decision, including the EU-U.S. Data Privacy Framework, or the European Commission's Standard Contractual Clauses.

4. SSL/TLS encryption

For security reasons this website uses SSL/TLS encryption. You can recognise an encrypted connection by “https://” in your browser's address bar.

5. Contact by email

If you contact us by email (info@valplex.de), we process the information you provide (in particular your email address, name and the content of your message) in order to handle your request. The legal basis is Art. 6(1)(b) GDPR where the request relates to the conclusion or performance of a contract, otherwise Art. 6(1)(f) GDPR (legitimate interest in responding to inquiries). We store this data until the purpose of its processing no longer applies and no statutory retention obligations prevent deletion.

6. Cookies and external content

We do not set cookies on this website, nor do we use comparable storage technologies (such as local storage). Fonts are provided locally. The website embeds no external resources (such as web fonts or scripts from third-party servers) and uses no analytics, tracking or marketing services.

GitHub may set cookies on its own domains (in particular github.com and github.io). This website is served under our own domain, valplex.de. To the best of our knowledge, GitHub Pages does not set cookies on this domain. The access data described in section 3 arise on the server side and are not cookies.

Consent under Section 25 TDDDG is therefore not required.

To exercise these rights, a message to the contact details above is sufficient.
